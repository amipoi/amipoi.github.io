Movie recommender

Practical Statistical Learning, UIUC team project

Item-based collaborative filtering on MovieLens, built from scratch: a mean-centered sparse ratings matrix, cosine similarity between movies, the top 30 neighbors per movie, and a popularity fallback for users with too few ratings.

What I learnedThe minimum number of shared raters acts like a hyperparameter. Raising it from 3 to 250 stopped R-rated films from showing up next to Toy Story, and it produced lists like this one: suspense and adventure classics for a sci-fi action fan.

Power vs. efficiency: a D3 narrative

Data Visualization, UIUC final project

An interactive slideshow in D3.js covering 972 car models from 1990 to 2017, each averaged across its production years. It compares how Asian, American, and European makers trade fuel economy for horsepower, with horsepower on a log scale so the points spread evenly. The chart above is a small rebuild from my project data, so try the buttons.

The storyAsian makers lead on efficiency (27.5 highway MPG on average), American makers sit in the balanced middle, and European makers go for power (about 354 hp on average).

AirTrace: allergy risk app on Google Cloud

Database Systems, UIUC team project

A cloud-hosted web app that turns cached pollen forecasts, each user's allergen sensitivities, and nearby California street-tree data into a personal seven-day allergy risk forecast. The Flask app runs in a Docker container on Cloud Run against Cloud SQL for MySQL. Cloud Scheduler wakes it at 7 AM every day to send Web Push alerts on high-risk days.

  • Google Cloud Run
  • Cloud SQL (MySQL)
  • Cloud Scheduler
  • Docker
  • Flask
  • Web Push
What I learnedSplitting the work made the cloud piece simple. The database decides when an alert is due (a trigger fills a queue), and the scheduled Cloud Run job only sends what is queued, so every alert is queued once and marked sent after delivery.

Predicting daily sunshine

Statistical Modeling in R, UIUC team project

Multiple regression on about 56,000 Australian weather observations. We averaged the 9am and 3pm readings to remove collinearity, dropped location factors, and selected with BIC. The result is an explainable model built on humidity, cloud cover, evaporation, rainfall, wind, temperature, and day of year.

  • Linear regression
  • BIC selection
  • Diagnostics
  • R
What I learnedCutting from 71 predictors to 12 cost almost no accuracy, and train and test RMSE stayed close, so the simpler model held up on unseen data.
