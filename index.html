What I found A lag in price increases was distorting unit demand. The validation checks I built to correct forecasted volumes prevented a 30% overstock.

Movie recommender

Practical Statistical Learning, UIUC team project

Item-based collaborative filtering on MovieLens, built from scratch: a mean-centered sparse ratings matrix, cosine similarity between movies, the top 30 neighbors per movie, and a popularity fallback for users with too few ratings.

What I learnedThe minimum number of shared raters acts like a hyperparameter. Raising it from 3 to 250 stopped R-rated films from showing up next to Toy Story.
  • Collaborative filtering
  • Sparse matrices
  • Python

Historical menu data cleaning

Data Cleaning for Data Science, UIUC final project

Cleaned a multi-table historical menu dataset: standardized free-text event names in OpenRefine, validated dates in Python, and compared before-and-after results with SQL in SQLite.

What I learnedA fix only counts if you can prove it and repeat it, so I mapped the full pipeline as a YesWorkflow provenance graph.
  • OpenRefine
  • pandas
  • SQL
  • Data provenance

Predicting daily sunshine

Statistical Modeling in R, UIUC team project

Regression on Australian weather data, comparing additive, AIC, BIC, and interaction models with Breusch–Pagan, Q–Q, VIF, and Cook's distance diagnostics.

What I learnedThe interaction model fit best on paper but needed nearly 2,000 terms. BIC came close with 71, so we picked the model we could explain.
  • Regression
  • Model selection
  • R

Simulation studies

Statistical Modeling in R, UIUC

Monte Carlo experiments showing how noise affects significance tests, RMSE-based model selection, and statistical power when the true model is known.

What I learnedTest RMSE picked the true model only about 45% of the time, and less often as noise grew. Worth remembering in any forecast-model comparison.
  • Simulation
  • Hypothesis testing
  • R
